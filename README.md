# Flutter note app with Firebase

A note app created with firebase + flutter + shared preferences + secure storage

## Project features
 This Project includes :

 1. Firebase authentication,
 2. Google sign in
 3. Role based Access
 4. Password reset
 5. Remember me ( Remember password ) uaing secure storage
 6. Light & dark theme toggle and save the theme using shared preferences
 7. Localization support
 8. Searching notes
 9. Filter notes by category
 10. Supports CRUD operation
 11. Supports form validations
 12. Checks last updated at
 13. Supports real time internet connection checking
 14. Save searched history using shared preferences
 15. Supports shimmer effect
